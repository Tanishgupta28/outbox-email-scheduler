{\huge\bfseries Email Scheduling Dashboard\par}
\vspace{8pt}
A responsive React and TypeScript dashboard schedules test emails through an Express API, MySQL persistence, and a separate Redis/BullMQ worker. Durable queue recovery, configurable rate limits, bounded retries, and Ethereal SMTP previews make scheduling and delivery status easy to demonstrate across process restarts.
